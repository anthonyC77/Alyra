# Formation Alyra : exercices Solidity (2021)

Exercices réalisés de mars à mai 2021 pendant la formation « Développeur blockchain » d'Alyra, diplômante, suivie en ligne.

| Fichier | Sujet |
|---|---|
| `Voting.sol`, `Voting2`, `VotingCorrected`, `Voting.js` | système de vote : électeurs, propositions, vote, dépouillement |
| `Attack`, `EtherStore`, `ReEntrancyGuard` | une attaque par réentrance, puis la protection qui la bloque |
| `ERC20Token`, `erc20.test.js` | un jeton ERC-20 et ses 7 tests |
| `Crowdsale` | vente de jetons |
| `Admin.sol` | liste blanche et liste noire d'adresses, gérées par un administrateur |
| `Random.sol` | tirage pseudo-aléatoire dans un contrat |

## Les autres dépôts de la formation

- [Maticulum](https://github.com/Maticulum/Maticulum) : le projet final, une dApp qui délivre des diplômes en NFT sur Polygon, menée à quatre.
- [Staking](https://github.com/anthonyC77/Staking) : staking de jetons ERC-20, récompenses calculées avec les prix Chainlink.
- [VoteDefiAlyra](https://github.com/anthonyC77/VoteDefiAlyra) : le défi « système de vote », contrat et front.
- [DEFI-Vote](https://github.com/anthonyC77/DEFI-Vote) : le front React de ce défi ; [Voting](https://github.com/anthonyC77/Voting) et [Vote](https://github.com/anthonyC77/Vote) en sont les versions publiées.
- [VoteDefi](https://github.com/anthonyC77/VoteDefi) : premier envoi du même défi, sans le front.
- [whitelist](https://github.com/anthonyC77/whitelist) : le défi « liste blanche », c'est-à-dire le modèle ci-dessous, déployé sur Heroku.
- [SimpleStorage](https://github.com/anthonyC77/SimpleStorage) : le tutoriel SimpleStorage de Truffle, publié.
- [whitelist-system-with-heroku](https://github.com/anthonyC77/whitelist-system-with-heroku) : le modèle de départ du défi « liste blanche », écrit par d'autres.
